->sudo apt install systemd-timesyncd
->systemctl status systemd-timesyncd
->
->open "sudo nano /etc/systemd/timesyncd.conf" and write server ip addr to the client,
  [Time]
  NTP=172.16.16.57
->sudo timedatectl set-ntp true

->sudo systemctl enable --now ntp
->sudo systemctl restart ntp     # or ntpd
->sudo systemctl status ntp

change date in client(Rasp-Pi)
->sudo timedatectl set-ntp false
->sudo timedatectl set-time "2022-01-12 10:30:00"
->systemctl status ntpd*
